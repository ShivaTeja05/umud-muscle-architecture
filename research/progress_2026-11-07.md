## GasFasTrack audit

Public source: https://zenodo.org/records/2598553 (CC BY 4.0).
The first schema audit found all 45 root `TrackedData.mat` files:
five subjects (1,3,4,5,6), three days, three examiners. Top-level variables
alone were insufficient: `Data.clips`, `Data.Params`.

The improved schema audit was pushed as version 2 of private CPU kernel
`shivateja005/umud-gasfastrack-schema-probe`. It reuses the first metadata
kernel's archive and exports nested schemas and a small ZIP of MATLAB files.
It uses no accelerator and has no competition data attached.

The public `matlab.zip` source was separately inspected:

- `trackfascicle.m` writes `fascicle.automatic` and, only after explicit
  validation, `fascicle.validate`. Fields include length, pennation,
  trackFrames, insertDeep, insertSup, plotInsertions.
- `trackpoints_validate.m` copies tracked aponeuroses into the validation
  frame and asks the observer to redraw the fascicle. Thus validation is
  human fascicle supervision conditional on tracked aponeuroses, not fully
  independent manual geometry. MT supervision cannot be claimed from this.
- `calculatefascicle.m` computes FL from intersections in millimetres using
  separate px2mmX and px2mmY. PA uses fitted pixel slopes, not explicitly
  anisotropy-corrected physical slopes. Preserve this convention in the audit.
- Saved `_automatic.mp4` videos are cropped and have tracking overlays. Do
  not use those rendered overlays as image input for training or scoring.
  Raw, matching source frames are required before a valid paired benchmark.
- TimTrack dataset 3 derives from this source. It is not a second independent
  source. Subject identity and frame duplication must be checked across them.
